# Частное техническое задание (ЧТЗ): Подсистема промышленной телеметрии

Настоящее Частное техническое задание (ЧТЗ) разработано в соответствии с требованиями стандартов серии **ГОСТ 34** (**ГОСТ 34.602-89**) и регулирует создание подсистемы сбора и обработки телеметрической информации промышленного оборудования на объектах КИИ (187-ФЗ).

---

## 1. Общие сведения

- **Полное наименование подсистемы**: Подсистема сбора и обработки телеметрической информации (ПСОТИ).
- **Шифр темы**: `ЧТЗ-ТЕЛ-2024-КИИ`.
- **Заказчик**: Предприятие контура ГК Росатом / Объект КИИ.
- **Назначение**: Обеспечение непрерывного мониторинга технологических показателей промышленной автоматизации (АCУ ТП) и безопасная передача данных в аналитический контур.

---

## 2. Функциональные требования (FR)

| Идентификатор | Наименование функции | Описание функционального требования |
| :--- | :--- | :--- |
| **FR-01** | Сбор данных АСУ ТП | Опрос контроллеров (ПЛК) по протоколам Modbus TCP и OPC UA с периодичностью не менее 100 мс. |
| **FR-02** | Валидация телеметрии | Проверка диапазонов допустимых значений (Out-of-Bounds) и фильтрация недостоверных отчетов. |
| **FR-03** | Буферизация при сбоях | Локальное хранение до 72 часов телеметрических данных на edge-узле при разрыве связи с ЦОД. |
| **FR-04** | Буферизация и передача | Шифрованная передача телеметрии по протоколу gRPC/mTLS в центральную БД. |

---

## 3. Нефункциональные требования (NFR) и SLA

| Категория | Требование / Метрика | Значение / Критерий приемки |
| :--- | :--- | :--- |
| **Производительность** | Пропускная способность | Обработка до 50 000 метрик в секунду (MPS) на узел. |
| **Задержка (Latency)** | Время доставки метрики | Latency $p_{99} \le 50$ мс от ПЛК до аналитической БД. |
| **Надежность (SLA)** | Коэффициент доступности | Доступность $99.95\%$; MTBF $\ge 10\,000$ часов. |
| **Безопасность (КИИ)** | Соответствие 187-ФЗ | Изоляция сетевых сегментов, взаимная аутентификация mTLS (ГОСТ Р 34.12-2015). |
