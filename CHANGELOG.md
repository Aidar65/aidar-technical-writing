# История изменений (Changelog)

Все заметные изменения в проекте портфолио зафиксированы в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Семантического версионирования](https://semver.org/lang/ru/).

---

## [1.3.0] - 2026-08-11

### Added
- **Практические кейсы:** реверс-инжиниринг для Курской АЭС-2 (краны, контракт 1,5 млн ₽)
  и комплекс поставок и Compliance (Росатом / ПРОРЫВ) — `docs/cases/`.
- **Локальный AI-контур:** схема безопасной работы с черновиками документации
  в закрытом периметре (Ollama + Aider + Qwen2.5-Coder, NDA / ЗОКИИ).
- **Метрики и контакты:** блок ключевых показателей на главной
  (контракты ~74,8 млн ₽, 3240 позиций, 100% ПДК ВК), NDA-дисклеймер, актуальные контакты.

### Fixed
- **UTF-8:** `valve-control.yaml`, `swagger.yaml`, `asyncapi.yaml` переписаны начисто —
  кракозябры устранены, исправлена опечатка ключа `asyncapi`.
- **Кодовые фенсы:** восстановлены переносы строк в ST/CODESYS (IEC 61131-3),
  cURL-примере и всех Mermaid-диаграммах (телеметрия, паспорт ТПА, AI-контур).
- **ГОСТ 34.602:** заголовок «Назначение и цели создания» разбит на отдельные слова.

### Changed
- Спецификации OpenAPI/AsyncAPI синхронизированы к единой версии 1.2.0.
- Telegram-контакт актуализирован: `@aidar_yarmakov`.

## [1.2.0] - 2026-08-09

### Added
- **ГОСТ 34.602:** ТЗ на модуль управления электроприводом ТПА в Markdown (`docs/reference/tz-gost34.md`).
- **ГОСТ 19.201:** ТЗ на сервисную утилиту калибровки концевых выключателей (`docs/reference/tz-gost19.md`).
- **AsyncAPI 2.6:** спецификация MQTT-потока телеметрии вибрации и температуры привода (`docs/reference/asyncapi.yaml`).
- **DocOps Quality Gate:** настроен `.vscode/settings.json` для линтинга русской и английской орфографии (Code Spell Checker).

### Fixed
- Исправлен деплой в GitHub Actions: переключён на нативный экшен `actions/deploy-pages@v4` с поддержкой `requirements.txt`.
- Приведены к строгому кодированию UTF-8 все файлы Markdown и YAML.
