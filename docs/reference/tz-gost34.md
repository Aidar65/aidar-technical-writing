# ТЕХНИЧЕСКОЕ ЗАДАНИЕ (ГОСТ 34.602-89)
## На модуль управления электроприводом ТПА в составе АСУ ТП
### ШИФР: ТЗ-34.602-VALVE-2026

---

## 1. ОБЩИЕ СВЕДЕНИЯ
Настоящее ТЗ распространяется на модуль **Valve Control API** (далее — Система), входящий в состав АСУ ТП верхнего уровня.

---

## 2. НАЗНАЧЕНИЕ И ЦЕЛИ СОЗДАНИЯ
Система предназначена для дистанционного управления затвором ТПА, фиксации концевых выключателей и передачи телеметрии крутящего момента по протоколу REST API / Modbus RTU.

---

## 3. ТРЕБОВАНИЯ К СИСТЕМЕ

### 3.1. Требования к функциональным характеристикам
1. Считывание текущего положения затвора (0–100%) с погрешностью не более 0.5%.
2. Фиксация сработки концевиков is_open и is_closed.
3. Время отклика API на команду управления — не более **200 мс**.

### 3.2. Требования к надежности (Класс безопасности 4)
1. Наработка на отказ (MTBF) — не менее 50 000 часов.
2. Автоматический переход в безопасное состояние (Fail-Safe) при потере связи.
