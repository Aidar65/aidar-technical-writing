# Глоссарий

Расшифровка аббревиатур, которые встречаются в портфолио.

| Термин | Расшифровка | Пример использования |
| :--- | :--- | :--- |
| **ЕСКД** | Единая система конструкторской документации | Комплект конструкторской документации оформляют по ЕСКД. |
| **ЕСПД** | Единая система программной документации | Программную документацию на систему разрабатывают по ЕСПД. |
| **ГОСТ 19** | Серия стандартов ЕСПД: правила разработки, оформления и обращения программной документации | Пояснительную записку к программе оформляют по ГОСТ 19.404. |
| **ГОСТ 34** | Серия стандартов на автоматизированные системы: стадии создания, состав и содержание документации | Техническое задание на подсистему телеметрии разработано по ГОСТ 34.602. |
| **ПМИ** | Программа и методика испытаний | Приёмочные испытания системы проводят по утверждённой ПМИ. |
| **ТУ** | Технические условия | Материал закупают по техническим условиям поставщика (ТУ). |
| **ТЗ** | Техническое задание | Разработку ведут на основании утверждённого ТЗ. |
| **РЭ** | Руководство по эксплуатации | Порядок работы оператора с системой описан в РЭ. |
| **ВСД** | Входной контроль сопроводительной документации | Поставленное оборудование принимают на площадку только после ВСД. |
| **ККС** | Kraftwerk-Kennzeichensystem — система кодов для маркировки систем и оборудования электростанций | Оборудование АЭС маркируют кодами ККС. |
| **ЕОС-Качество** | Единая отраслевая система управления качеством Госкорпорации «Росатом» | Несоответствия при приёмке фиксируют в ЕОС-Качество. |
| **ЕОНКОМ** | Единый отраслевой номенклатурный каталог оборудования и материалов | Позицию материала подбирают по коду ЕОНКОМ. |
| **ЗОКИИ** | Значимый объект критической информационной инфраструктуры | Подсистему телеметрии отнесли к ЗОКИИ по 187-ФЗ. |
| **УКЭП** | Усиленная квалифицированная электронная подпись | Пакет документов подписывают УКЭП. |
| **УНЭП** | Усиленная неквалифицированная электронная подпись | Внутренний документооборот допускает подписание УНЭП. |
