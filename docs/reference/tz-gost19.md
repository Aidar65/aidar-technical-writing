# ТЕХНИЧЕСКОЕ ЗАДАНИЕ (ГОСТ 19.201-78)
## На программу автоматической калибровки концевых выключателей
### ШИФР: ЕСПД.19201-01-VALVE-CALIB

---

## 1. ВВЕДЕНИЕ
Настоящее Техническое задание распространяется на программное обеспечение **ValveCalibService** (далее — Программа).

Программа предназначена для сервисного обслуживания и автоматической установки токовых нулей концевых выключателей и датчиков момента электроприводов ТПА.

---

## 2. ТРЕБОВАНИЯ К ПРОГРАММЕ

### 2.1. Требования к функциональным характеристикам
1. Программа должна обеспечивать пошаговый вывод затвора в крайние положения «Открыто» / «Закрыто».
2. Программа должна считывать сырые значения регистров Modbus RTU и вычислять калибровочные коэффициенты.
3. Программа должна записывать итоговые константы в энергонезависимую память EEPROM контроллера привода.

### 2.2. Требования к программной и аппаратной совместимости
* **Операционная система:** Linux (Astra Linux / Ubuntu 22.04 LTS).
* **Язык разработки:** Python 3.11+.
* **Аппаратные интерфейсы:** Адаптер USB-RS485 (протокол Modbus RTU, baudrate 9600-115200).
