# Спецификация mTLS и PKI для IoT-шлюза ТПА

Взаимодействие между электроприводом затвора и облачным контуром АСУ ТП (187-ФЗ ЗОКИИ).

---

## 1. Архитектура сертификатов (X.509 v3)

* **Root CA:** Корпоративный Удостоверяющий Центр (Offline).
* **Device Certificate:** Выпускается на ПЛК при первичной калибровке на заводе-изготовителе.

---

## 2. Валидация (OCSP Stapling)

Шлюз передает статус валидности через OCSP Stapling (RFC 6066). Обновление списков отзыва (CRL) — каждые 15 минут.
