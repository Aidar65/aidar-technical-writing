# История изменений (Changelog)

Все заметки о релизам документируются автоматически по стандарту Conventional Commits.

## [1.1.0] - 2026-08-09

### Добавлено (Features)
- Добавлен OpenAPI контракт для управления задвижкой (`feat(api)`).
- Добавлена схема телеметрии MQTT через AsyncAPI (`feat(api)`).
- Настроен локальный pre-commit хук для контроля качества разметки (`ci(hooks)`).

### Исправления (Fixes)
- Устранены битые ссылки в навигации MkDocs (`fix(nav)`).
- Исправлена кодировка и переносы строк в Mermaid-диаграммах (`fix(docs)`).
