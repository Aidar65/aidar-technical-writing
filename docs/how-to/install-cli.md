# Руководство по установке Valve Control CLI

Утилита командной строки для диагностики и калибровки концевых выключателей электропривода ТПА.

---

## 1. Системные требования

* Python >= 3.10
* Доступ к сервисному порту RS-485 / Modbus RTU

---

## 2. Установка через пакетный менеджер

Выполните команду в вашем терминале:

```bash
pip install valve-control-cli --extra-index-url [https://pypi.integra.ru/simple](https://pypi.integra.ru/simple)
