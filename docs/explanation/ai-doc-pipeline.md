# Спецификация пайплайна автоматической генерации и проверки документации на базе LLM

Настоящий документ описывает архитектуру внутреннего пайплайна генерации и проверки документации на базе нейросетевых моделей (LLM) в изолированных (Air-Gapped) контурах предприятий.

---

## Архитектура пайплайна (Ollama + Qwen2.5-Coder)

Пайплайн функционирует локально внутри изолированного периметра безопасности без доступа к внешним интернет-ресурсам.

```text
[ Исходники кода / OpenAPI ] 
           │
           ▼
[ Ollama Server (Qwen2.5-Coder) ] ── (Контекст: ГОСТ 34/19 + Diátaxis)
           │
           ▼
[ Генерация Markdown / Спецификаций ]
           │
           ▼
[ Quality Gate: markdownlint ] ── (Автопроверка в CI/CD)
```

---

## Компоненты архитектуры

1. **Ollama Inference Engine**: Локальный сервер инференса, развернутый в закрытом контуре.
2. **Qwen2.5-Coder LLM Model**: Специализированная языковая модель для обработки исходного кода, генерации OpenAPI и форматирования Markdown.
3. **Compliance & Quality Gates**: Модуль автоматической проверки сгенерированных текстов линтерами (`markdownlint`) и схематическими валидаторами перед коммитом в Git.

---

## Преимущества решения в закрытых контурах

- **Безопасность (Air-Gapped)**: Полное исключение утечек данных за пределы периметра компании.
- **Стандартизация**: Строгое соблюдение правил форматирования и структуры ГОСТ / Diátaxis на этапе генерации.
- **Скорость**: Сокращение времени на первичную подготовку технической документации до 70%.
