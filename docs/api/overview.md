# Интеграция Valve Control API

Быстрый старт по работе с REST API модуля управления запорно-регулирующей арматурой (ТПА).

---

## 🚀 Базовый поток интеграции

1. Запросите текущее состояние затвора через GET /api/v1/valves/{id}/status.
2. Проверьте флаги концевых выключателей (is_open, is_closed).
3. При необходимости отправьте управляющий импульс на электропривод.
